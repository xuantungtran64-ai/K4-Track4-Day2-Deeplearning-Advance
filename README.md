## Cấu trúc thư mục
- \code/\: Chứa mã nguồn Python đã hoàn thiện (\	rain.py\, \inference.py\, \losses.py\,...) và file \lab_day2.ipynb\.
- \predictions/\: Chứa các file CSV dự đoán của mô hình chung kết (F01) và mốc (T00) trên 3 seed.
- \curves/\: Chứa các biểu đồ Training/Validation Loss và F1 tương ứng.
- esults.xlsx\: Bảng tổng hợp số liệu thực nghiệm toàn bộ các bước.
- eport.md\: Báo cáo phân tích chuyên sâu về lý do chọn tham số.

## Cách chạy lại mã nguồn
1. Tải toàn bộ thư mục \code/\ và đưa lên môi trường Kaggle/Colab.
2. Tải dataset DeepWeeds theo hướng dẫn ở Bước 0.
3. Chạy lần lượt các cell trong \lab_day2.ipynb\ từ trên xuống dưới.
